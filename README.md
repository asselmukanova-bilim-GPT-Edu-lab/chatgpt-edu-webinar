# ChatGPT Edu: вебинар для регионов

Интерактивная презентация на русском и казахском языках, 34 слайда.

Откройте `index.html` в браузере. При локальном просмотре сохраняйте папки `assets`, `media` и файл `BilimAI_simulation_v2.html` рядом с презентацией. Для внешних ссылок нужен интернет.

## Содержание

- ChatGPT Edu, этика, интерфейс и промпты.
- Плагины Ustaz и Tarbie BilimAI Mektep.
- Симуляция и интерактивные предметные демонстрации.
- HTML-материалы, шаблон запроса и проверка результата.
- Практика, программа CHAMPIONS и обратная связь.

Стрелки переключают слайды, кнопки RU / KK меняют язык, меню «Главы» открывает содержание. Демонстрация BilimAI использует подготовленные экраны и не подключается к ChatGPT.

Это отдельная адаптация семинара. Исходные две части сохранены без изменений. Соответствие исходной и текущей нумерации находится в `slide-map.json`.

Версия находится в процессе сокращения под 60 минут; текущие отметки времени сохраняют промежуточный сценарий. Сведения о мероприятиях и интерфейсах соответствуют исходным материалам семинара.
